# 變色偵探隊

這是一份適合國小三年級自然課使用的 RWD 互動網頁教材，主題是「紫色高麗菜汁顏色變化」。

## 教學對象

國小三年級學生。

## 學習重點

- 觀察紫色高麗菜汁遇到不同水溶液後的顏色變化。
- 練習預測、觀察、比較、分類與歸納。
- 以生活化語言整理偏紅色、紫色不明顯、藍綠色三類結果。

## 教材功能

- 卡通自然教室首頁。
- 材料介紹與安全提醒。
- 「先預測，再實驗」互動流程。
- 學習紀錄表。
- 手機友善的點選分類任務。
- 5 題即時回饋小測驗。
- 學習總結與簡短教師補充區。

## 使用方式

直接開啟 `index.html`，或部署到 GitHub Pages 後從網站入口進入。

## 技術

純前端靜態網頁，不使用外部框架、CDN 或外部圖片。
